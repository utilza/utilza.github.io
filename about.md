Utilza Notes is where the team behind [Utilza](https://utilza.app) writes up the small technical jobs we keep getting asked about: DNS records that haven't spread, certificates that won't issue, tokens an API rejects, config files that parse differently on two machines.

Each guide explains one job from start to finish, with the commands to run and a checklist at the end. Where one of our tools saves a step, we link to it and say what it can and can't do.

Utilza itself is a collection of free browser tools: calculators, file converters, image and PDF tools, DNS and network checks, and developer utilities. Most of them run entirely in your browser, and none of them need an account.

If a guide is wrong or out of date, or there's a topic you'd like covered, write to us through the [contact page](https://utilza.app/contact).
